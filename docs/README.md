## 📖 Краткий обзор проекта

### Что это такое?

XX Auto Jobs Applier - это Python приложение, которое автоматизирует процесс поиска работы на hh.ru:

- 🔍 **Поиск вакансий** по вашим критериям
- 🤖 **AI фильтрация** вакансий по соответствию вашему резюме
- ✍️ **Автоматическое написание** сопроводительных писем
- 💬 **Ответы на вопросы** работодателей через LLM
- 📝 **Генерация резюме** под конкретную вакансию (опционально)
- 📊 **Детальная статистика** и логирование всех действий

### Как это работает?

```
┌─────────────────────────────────────────────────────────────┐
│  1. Вы настраиваете параметры поиска                        │
│     (должность, регион, зарплата, требования)               │
└───────────────────────┬─────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│  2. Приложение ищет вакансии через API hh.ru                │
│     (с учетом всех фильтров)                                │
└───────────────────────┬─────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│  3. AI оценивает каждую вакансию (1-100 баллов)            │
│     Учитывается: описание вакансии + ваше резюме            │
└───────────────────────┬─────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│  4. Если вакансия подходит (≥ порог):                       │
│     - AI отвечает на вопросы работодателя                   │
│     - AI генерирует сопроводительное письмо                 │
│     - Отправляется отклик через API                         │
└───────────────────────┬─────────────────────────────────────┘
                        │
                        ▼
┌─────────────────────────────────────────────────────────────┐
│  5. Результаты сохраняются:                                 │
│     - Успешные отклики → success.yaml                       │
│     - Пропущенные → skipped.yaml (с причиной)               │
│     - Ошибки → failed.yaml                                  │
└─────────────────────────────────────────────────────────────┘
```

### Технологический стек

**Основные технологии:**
- 🐍 Python 3.12+
- 🌐 Selenium (для веб-автоматизации)
- 🧠 LiteLLM (унифицированный доступ к LLM)
- ✅ Pydantic (валидация данных)
- 📊 YAML (конфигурация и логи)

**Интеграции:**
- HeadHunter API (поиск вакансий, отклики)
- OpenAI API / Google Gemini (AI ответы)
- Telegram Bot API (уведомления)

**Поддерживаемые LLM:**
- OpenAI (GPT-4o, GPT-4o-mini)
- Google Gemini (gemini-2.0-flash) ⭐ рекомендуется
- Claude (Anthropic)
- GigaChat (Сбер)
- Ollama (локально)
- HuggingFace

## 🎯 Основные возможности

### Режимы работы

| Режим | Переменная | Описание |
|-------|-----------|----------|
| **Нормальный** | `MONKEY_MODE = False` | AI фильтрует вакансии, откликается только на подходящие |
| **Обезьяний** | `MONKEY_MODE = True` | Откликается на ВСЕ вакансии подряд без анализа |
| **Генерация резюме** | `RESUME_MODE = True` | Создает резюме под каждую вакансию (HTML/PDF) |
| **Проверка писем** | `COVER_LETTER_MODE = True` | Только генерирует письма, не откликается |
| **Статистика навыков** | `SKILL_STAT_MODE = True` | Собирает статистику по требуемым навыкам |

### Настройки поведения

**В `src/app_config.py`:**

```python
# Порог "интересности" вакансии (1-100)
JOB_IS_INTERESTING_THRESH = 70  # Только вакансии ≥ 70 баллов

# Поднимать резюме при каждом запуске
RAISE_RESUME = True  # Макс. раз в 4 часа

# Минимальное время на отклик (антибан)
MINIMUM_WAIT_TIME_SEC = 10

# Выбор LLM
LLM_MODEL_TYPE = "gemini"  # openai, claude, gemini, ollama
LLM_MODEL = "gemini-2.0-flash"  # конкретная модель

# Креативность AI (0-1.5)
TEMPERATURE = 0.4  # 0 = строгий, 1.5 = креативный
```

**В `data_folder/search_config/search_config.yaml`:**

```yaml
# Лимиты откликов
max_applies_num: 200              # За один запуск
max_total_applies_num: 1500       # Всего за все время (опционально)

# Ограничения
apply_once_at_company: true       # Не более 1 отклика на компанию
skip_companies_with_test: false   # Пропускать вакансии с тестовым заданием

# Черный список
job_blacklist: Google, Meta       # Компании для игнорирования

# Готовое письмо (опционально)
cover_letter: |
  Ваш текст сопроводительного письма для всех вакансий...
  # Если пусто - AI будет генерировать под каждую вакансию
```

## 🔐 Безопасность

### Что хранится локально

✅ Все данные остаются на вашем компьютере:
- API токены и пароли
- История откликов
- Логи работы
- Сессии браузера

### Что отправляется в LLM

⚠️ В LLM отправляются только анонимизированные данные:
- Текст вакансий
- Ваше резюме **с замененными личными данными**
  - ФИО → Вымышленное имя
  - Телефон → Dummy номер
  - Email → Dummy адрес

**Механизм анонимизации** описан в `src/constants.py`:
```python
DUMMY_PERSONAL_INFO_MALE = {
    "first_name": "Аристаний",
    "phone": "+7 (933) 575-35-35",
    "email": "aristaniy93@gmail.com",
    # ...
}
```

### Рекомендации

1. **Исключите из Git:**
   ```bash
   git update-index --assume-unchanged data_folder/secrets/secrets.yaml
   ```

2. **Не делитесь:**
   - Содержимым `data_folder/secrets/`
   - Файлами `llm_api_calls.yaml` (могут содержать личные данные)

3. **Регулярно обновляйте токены:**
   - Приложение делает это автоматически
   - Но при длительных перерывах (недели) потребуется пересоздание

## 📊 Выходные данные

После запуска в `data_folder/output/` создаются файлы:

| Файл | Назначение |
|------|-----------|
| `success.yaml` | ✅ Успешные отклики (URL, компания, должность) |
| `skipped.yaml` | ⏭️ Пропущенные вакансии + причина |
| `failed.yaml` | ❌ Ошибки при отправке откликов |
| `answers.yaml` | 💾 Кэш ответов LLM (экономия денег) |
| `llm_api_calls.yaml` | 📝 Все запросы к LLM + стоимость |
| `cover_letters.txt` | 💌 Все сгенерированные письма |
| `resume.yaml` | 👤 Информация о вашем резюме |

**Для анализа:**
- Проверяйте `cover_letters.txt` на "кринж"
- Смотрите `llm_api_calls.yaml` для подсчета расходов
- Анализируйте `skipped.yaml` для оптимизации фильтров

## 💰 Стоимость использования

### Расходы на LLM

Стоимость зависит от выбранной модели (настраивается в `app_config.py`):

| Модель | Входящие токены | Исходящие токены | ~Стоимость на 100 вакансий* |
|--------|-----------------|------------------|----------------------------|
| **gemini-2.0-flash** | $0.10 / 1M | $0.40 / 1M | ~$0.50-1.00 |
| gpt-4o-mini | $0.15 / 1M | $0.60 / 1M | ~$0.75-1.50 |
| gpt-4o | $2.50 / 1M | $10.00 / 1M | ~$12.50-25.00 |

*Примерный расчет при ответах на вопросы + генерации писем

**Рекомендация:** Используйте `gemini-2.0-flash` - лучшее соотношение цена/качество.

### Отслеживание расходов

Проверяйте файл `llm_api_calls.yaml`:
```yaml
- timestamp: 2025-10-22 14:30:15
  prompt: "Оцени вакансию..."
  response: "85"
  input_tokens: 1523
  output_tokens: 3
  cost_usd: 0.0001523  # Стоимость этого запроса
```

В конце работы приложение выводит общую стоимость.

## 🛠️ Решение проблем

### Быстрая диагностика

**Приложение не запускается:**
1. Проверьте версию Python: `python --version` (должно быть 3.12+)
2. Убедитесь, что все зависимости установлены: `pip install -r requirements.txt`
3. Проверьте наличие файлов в `data_folder/`

**Ошибки API hh.ru:**
1. Проверьте токены в `secrets.yaml`
2. Убедитесь, что токены не истекли
3. См. раздел "Получение токенов" в основном README

**LLM не отвечает:**
1. Проверьте `llm_api_key` в `secrets.yaml`
2. Убедитесь в наличии средств на балансе API
3. Для OpenAI: включите VPN (европейская страна/США)
4. Проверьте логи в `llm_api_calls.yaml`

**Подробнее:**
- См. раздел "Проблемы" в [../README.md](../README.md)
- Создайте issue на [GitHub](https://github.com/beatwad/XX_Auto_Jobs_Applier/issues)
- Спросите в [Telegram чате](https://t.me/xx_auto_job)
